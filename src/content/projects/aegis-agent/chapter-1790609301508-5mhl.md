## 意图十维规范与数据契约架构计划

Q1：十维规范与数据契约

交付：
- 十个维度的正式定义
- 枚举和结构对象
- Taxonomy 版本
- Query IR
- Gate 状态
- Reason Code
- JSON Schema
- 合法性约束
- 状态转换图
- 边界案例

Q2：确定性门控骨架

实现：
- D1 Adapter
- D8 Policy 接口
- D7 Risk Policy 接口
- Gate Engine
- 降级语义
- 编译失败语义

Q3：D2–D6 结构分析

实现：
- 问题类型分析
- 信息需求分析
- 任务图
- 结构置信度
- 验证计划
- 节点级证据

Q4：D9/D10 横切策略

实现：
- 时效与缓存策略
- 单/多智能体选择建议
- 执行预算
- 通信预算
- 计划后 Finalization

Q5：十维专项评测

建议指标：
- D1/D2：宏 F1、混淆矩阵、置信度校准
- D3：来源集合 F1、闭合状态准确率
- D4：节点 F1、边 F1、拓扑类型准确率
- D5：Brier Score、ECE、重规划预测准确率
- D6：验证器覆盖率、错误放行率
- D7：高风险漏判率
- D8：越权漏判率、误拒绝率
- D9：陈旧缓存错误率
- D10：质量、成本、延迟、通信量 Pareto 曲线

Q6：接入交互层

将 Query IR 映射为：
needs_clarification
denied
requires_approval
proposal_ready
ready
然后再实现澄清、确认、拒绝、执行和 SSE。
