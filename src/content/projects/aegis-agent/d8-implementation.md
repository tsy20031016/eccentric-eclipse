## 1. 设计目的与位置

D8 回答两个问题：当前主体能否使用相关能力；现在能否对这个真实资源执行这次动作。计划前 D8 位于 D1 之后、D7 之前，确定能力范围；计划后 D8 位于任务图、验证方案及动作绑定之后，执行真实资源级裁决。工具执行前再复检，计划前允许不能覆盖计划后拒绝。

## 2. 输入与可信身份

`PrincipalContext` 必须来自可信认证边界，记录主体、租户、角色、scope 和权限快照。用户文本、session_id、任意身份声明及模型输出均不能构造授权主体。

用户输入提供待分析请求，服务端提供红线与权限策略。模型只提取 `AccessClaim`，包含动作、资源类型、租户、数据等级及来源线索，不提供授权结论。

## 3. 两个可替换企业组件

`EnterpriseRedlinePrecheck(request, principal, claim=None)` 负责企业红线；`PermissionPolicyAdjudicator(principal, claim)` 负责权限策略。两个 callable 分别通过 `AUTHORIZATION_REDLINE_POLICY_PATH` 与 `AUTHORIZATION_PERMISSION_POLICY_PATH` 装配，可以独立替换。

JSON 是默认适配格式，企业可以实现协议连接内部 RBAC/ABAC 或策略中心。策略加载严格检查版本、未知字段和重复规则；权限默认效果只能为拒绝。

## 4. 计划前固定流程

流程为原文红线预检 → LLM AccessClaim 提取 → 结构化红线复检 → 确定性权限裁决。原文检查尽早阻断明确红线；结构化检查进一步处理模型提取出的访问声明。模型解析层拒绝 allow、decision、policy 等授权字段。

权限逐项裁决原子请求：显式拒绝优先、未命中默认拒绝、跨租户必须显式授权。部分允许时输出允许、拒绝与剪枝能力，不放行整个原始组合请求。模型错误、策略故障和证据未知不会收敛为允许。

`PrePlanAuthorization` 保留状态、能力清单、AccessClaim、策略与权限快照版本、命中规则、原因码及权限义务，并固定要求计划后复检。能力键只是规划上界，不是任意具体资源的执行许可。

## 5. 部分允许与任务范围

组合请求的越权分支不能只通过删除能力键处理，原文中的越权目标仍可能影响后续模型。可信上游须明确形成获准任务片段；S25 对部分允许请求要求修订任务，不直接沿用原文继续执行。

D2–D6 对照能力键和后果记录检查范围，但不能仅凭文本证明语义剪枝正确。治理范围检查与自然语言理解质量需要分别验证。

## 6. 计划后动作与资源绑定

`PlannedAction` 绑定计划 ID、修订、节点、工具调用 ID、能力键、工具名及规范 JSON 参数。可信 `TargetResolver` 将调用解析为 `ResolvedTarget`，提供实际资源 ID、租户、数据等级、来源系统、资源版本、目标接收方和批量规模。

模型生成的资源描述不得直接成为权限真相。`BoundAction` 指纹绑定参数与解析后的资源版本，防止复检或审批后偷换目标。适配器必须保证真实调用与绑定资源一致。

服务先校验上游范围、节点、版本和验证覆盖，再对真实资源重跑红线与权限规则。规则支持具体资源 ID 和来源系统限制；策略异常、权限快照漂移和版本变化返回未决，不降级为允许。

## 7. 执行门与运行期复检

`recheck_plan()` 检查动作覆盖和调用 ID 唯一性，并标记受阻节点的依赖下游。`PostPlanExecutionGate.execute()` 在工具调用前重新解析资源、运行 D8/D7，并要求可信处理器确认权限义务已经落实。

人工批准不能覆盖权限拒绝。批准需要可信存储原子、一次性领取；领取前再复检并核对动作指纹。新增节点、补偿、重试及验证器额外资源访问也必须作为具体动作接受检查。

## 8. 模块实现与验收

`app/authorization/` 实现身份及访问模型、协议、策略加载、红线、声明提取、计划前服务与装配；`app/post_plan/` 实现真实资源绑定、节点级复检及执行门。

S15 的 D8 针对性筛选为 35 个用例通过，覆盖默认拒绝、显式拒绝、跨租户、剪枝、非法模型 JSON 和企业组件替换；S22 的 D8/D7 联合验收为 17 条离线用例，覆盖资源白名单、策略漂移、义务与批准后资源变化。数字为历史验收，不代表真实企业 IAM 已全部联调。

## 9. 当前接线与生产边界

S25 已将计划前及计划后 D8 接入统一编译和受控执行，S27 进一步接入可信主体、会话绑定及资源隔离。编译开关关闭时的兼容 ReAct 路径不能视为已通过全部十维关口。

真实企业资源目录、细粒度来源适配、可信审批存储及批准后恢复仍需集成。注册工具名称本身不授予执行许可，企业适配器必须落实真实资源解析、当前授权、权限义务及外部副作用控制。
