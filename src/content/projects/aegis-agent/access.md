## 1. 用户入口与控制台

- Web 控制台（浏览器中的操作界面）：提供系统总览、任务执行、执行轨迹、知识检索、记忆查询、评测基线和架构说明，共 7 个页面。
- HTTP API（通过网络请求调用后端能力的接口）：支持提交任务、查询工具、查询运行列表和详情、检索知识、读取记忆、查询当前身份。
- CLI（命令行入口）：支持在终端直接提交任务，例如 python -m app.agent "帮我计算 12345 * 6789"。
- 后端使用 FastAPI（Python Web 框架，用于定义接口、校验请求并生成接口文档）；前端使用 React（构建交互页面的 JavaScript 库）。
任务页面可以添加多条内容，填写类型提示、文件名和 MIME（描述内容格式的媒体类型，例如 application/json）。执行后会回填服务端会话标识，方便继续同一会话。
代码：[后端入口](D:/AI_Project/aegis-agent/app/main.py)、[控制台页面路由](D:/AI_Project/aegis-agent/frontend/src/router.tsx)。


## 2. 可信身份接入与资源隔离

- 支持 Bearer token（持有即可提交给服务端验证的访问令牌） 接入。
- 支持 OAuth2 令牌内省（向可信身份服务查询令牌是否有效及其权限）：校验有效状态、用户、租户、签发者、适用服务和有效期。
- 用户和租户身份由服务端验证结果构造，客户端填写的身份字段不能覆盖它。
- 根据 scope（令牌授予的具体操作权限） 检查任务执行、工具查询、轨迹查询、记忆读写和知识检索权限。
- 同名会话按租户和用户隔离；执行轨迹仅展示当前主体的数据；记忆按租户和用户划分；知识索引按租户选择。
- 接口查询与 Agent（执行任务的智能代理）工具使用同一资源访问上下文，覆盖工具调用路径。
浏览器令牌只保存在页面内存中，刷新后需要重新接入。切换身份会清理私有页面状态并丢弃旧身份的迟到响应；认证失效会清除凭据。
实现说明：[可信接入与资源隔离](D:/AI_Project/aegis-agent/docs/S27_section1_1_trusted_access.md)。



## 3. 输入识别、解析与标准化


已有 Input Gateway（输入网关：把外部输入转换成统一内部格式的入口），处理顺序为：
原始输入校验 → 类型识别 → 按类型解析 → 标准化 → 解析结果校验。
- 根据用户声明、MIME、文件扩展名和内容特征识别类型，不调用模型进行识别。
- 支持文本、代码、JSON（键值与数组组成的数据格式）、CSV（按行列组织的分隔值文本）、Markdown（轻量文本标记格式）、XML（使用标签组织数据的格式） 等输入。
- 语法解析失败时保留原文并记录告警；资源超限直接拒绝。
- 前端展示解析摘要：识别类型、解析状态、告警数量、实际文本字节和附件声明大小。
附件目前只有描述信息：可以填写文件名、类型、声明大小，但不会上传、读取或存储文件。识别出文件或二进制类型，也不意味着已经具备文件内容处理能力。
代码：[输入管道](D:/AI_Project/aegis-agent/app/input/pipeline.py)、[内容与附件编辑器](D:/AI_Project/aegis-agent/frontend/src/components/ContentEditor.tsx)。


## 4. 输入资源保护与接口契约

- 按实际接收字节限制请求正文，默认上限 2,000,000 字节。
- 限制内容与附件条数、文本字符数和字节数、附件声明大小、解析深度与节点数，以及 CSV 行列数。
- 分开计量 UTF-8（可变长度字符编码） 文本实际字节与附件声明字节，避免把中文字符数当成字节数。
- 使用严格字段类型，例如整数位置拒绝布尔值、浮点数和数字字符串。
- 返回统一错误结构，包含稳定错误码、字段位置和限额信息；内部异常对外隐藏详细错误。
- 系统提示词覆盖默认关闭，认证模式下还需要专门调试权限。
- 使用 OpenAPI（机器可读的接口描述规范） 增量生成前端类型，并检查前后端契约是否发生漂移。
实现说明：[输入资源保护与契约治理](D:/AI_Project/aegis-agent/docs/S28_section1_2_input_contract.md)。


## 5. 请求治理与故障定位

- 建立三个关联标识：request_id（HTTP 请求编号）、input_id（标准化输入编号）、run_id（执行编号）。
- 响应返回请求编号；控制台支持复制关联编号，并在有权限时直达 Trace（执行轨迹：记录一次任务执行过程的运行记录）。
- 默认只采集状态、大小、耗时、工具名等运行事实；正文日志和轨迹正文需要显式开启。
- 将存活探针、就绪探针和受保护运维诊断分开。公开探针只确认进程及本地初始化状态，不调用模型或身份服务。
- 任务入口具备有界并发和 FIFO（先进入队列的请求先获得执行机会） 排队：默认每进程 8 个执行名额、16 个等待名额、排队等待 2 秒。
- 队列满或等待超时返回明确的超载错误，以及 Retry-After（建议再次尝试前等待的时间）。
这些容量限制目前只作用于单进程，多进程、多实例之间不共享配额。
实现说明：[请求治理与运维可观测性](D:/AI_Project/aegis-agent/docs/S29_section1_3_request_governance.md)。


##6. 前端错误处理与数据来源提示

- 统一处理认证失效、权限不足、输入超限、服务超载、网络断连和客户端等待超时；客户端等待上限为 120 秒。
- 网络失败时保留请求编号，提示先核对执行轨迹；不会自动重试。
- 客户端超时或断连不保证任务取消，服务端可能继续执行。
- 生产构建关闭历史快照回退；演示构建允许展示快照，并明确标注“历史数据、非实时、非当前身份或租户”。
- 普通用户进入实时模式只需要就绪状态与有效身份，不强制要求运维诊断权限。
