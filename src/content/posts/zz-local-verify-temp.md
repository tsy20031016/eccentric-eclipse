## 什么是极限

极限是数学分析的核心概念。

行内公式：当 $x \to 0$ 时，$\sin x \approx x$。

块级公式：

$$
\lim_{x \to 0} \frac{\sin x}{x} = 1
$$

## 代码示例

```js
function fib(n) {
  if (n <= 1) return n;
  return fib(n - 1) + fib(n - 2);
}
```
